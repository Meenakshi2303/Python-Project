# Electric Vehicles Data Analysis
Developed a **Python-based EV Data Analysis project** for informed vehicle selection

Analyzed **53 EV models across 25 features** including price, range, battery and engine power

Performed **data preprocessing:** missing value imputation, duplicate removal and outlier detection using Z-Score

Filtered EVs based on **user budget and minimum range** criteria

Conducted **manufacturer-wise grouping and average battery capacity** analysis

Visualized b**attery vs. range relationships** using scatterplots and facet grids with Drive type insights

Created a **correlation heatmap** to identify strong positive and negative feature relationships

Built an **EV_Recommendation class** to return top 3 EVs based on user-specified budget, range and battery

Conducted **two-sample t-test** to compare average engine power between Tesla and Audi

Delivered **actionable insights and recommendations** for users to select EVs based on price, range, battery and engine power
